# Roadmap บทเรียน (ลำดับที่แนะนำ)

> รัน `/learn` ครั้งละ 1 บท (~10 นาทีอ่าน)
> `[ ]` = ยังไม่เขียน  `[x]` = เขียนแล้ว

1. [ ] **หุ้นคืออะไร** — เป็นเจ้าของบริษัทยังไง, ได้เงินจาก 2 ทาง (ราคาขึ้น + ปันผล)
2. [ ] **ETF และกองทุนรวม** — ซื้อหลายบริษัทในทีเดียว, ต่างกันยังไง
3. [ ] **ความเสี่ยงกับการกระจายความเสี่ยง** — ทำไมไม่ควรเอาไข่ทุกฟองใส่ตะกร้าใบเดียว (และเมื่อไหร่คนยังเลือกทำ)
4. [ ] **ค่าธรรมเนียม** — ค่าคอม, ค่าแปลงเงิน, expense ratio กินผลตอบแทน 6 ปีไปเท่าไหร่
5. [ ] **DCA vs ลงก้อนเดียว** — ทยอยลงทุนเดือนละเท่า ๆ กัน เทียบกับลงทีเดียว
6. [ ] **อัตราแลกเปลี่ยน** — ลงทุนหุ้นสหรัฐฯ แต่ใช้เงินบาท ค่าเงินมีผลยังไง
7. [ ] **ภาษี** — ภาษีปันผลหุ้นสหรัฐฯ, กฎเงินได้จากต่างประเทศของไทย
8. [ ] **อ่านงบการเงินแบบง่าย** — รายได้, กำไร, กระแสเงินสด
9. [ ] **Valuation พื้นฐาน** — P/E คืออะไร, หุ้นแพงหรือถูกดูยังไง
10. [ ] **วงจรตลาดและฟองสบู่** — ตัวอย่างฟองสบู่ดอทคอม 2000, ตลาดหมี 2022
11. [ ] **จิตวิทยาการลงทุน** — FOMO, panic sell, ทำไมคนส่วนใหญ่ซื้อแพงขายถูก
12. [ ] **อ่านข่าวไม่ให้โดนหลอก** — แยกข่าวจริง/ความเห็น/การปั่น, กลุ่มไลน์, มิจฉาชีพการลงทุน
